# AstrBot 群典插件

让群友的抽象发言变成经典罢！😋

## 环境要求

- AstrBot `>=4.24.2,<5`
- OneBot 11（AstrBot `aiocqhttp` 适配器）
- Python 依赖由 `requirements.txt` 安装

插件只支持群聊。数据按群隔离，私聊或其他平台不会访问群典数据。

## 指令和关键词

| 指令             | 说明                               |
| ---------------- | ---------------------------------- |
| /添加群典        | 引用普通消息或合并转发后收录       |
| /群典            | 随机发送当前群群典                 |
| /群典 @某人      | 随机发送该成员的群典               |
| /群典 info       | 查看当前群汇总统计                 |
| /爆典 @某人 [页码] | 按时间查看该成员参与的全部群典   |
| /删除群典 <文字> | 预览正文包含该文字的全部待删除记录 |
| /确认删除        | 在预览后的 60 秒内确认删除         |

| 关键词     | 说明                         |
| ---------- | ---------------------------- |
| 群典       | 随机发送当前群群典           |
| 群典 @某人 | 随机发送该成员的群典         |
| 爆典 @某人 [页码] | 查看该成员的完整群典合集   |
| 添加群典   | 引用普通消息或合并转发后收录 |

默认可直接使用精确关键词 `添加群典`、`群典` 和 `爆典`。关键词开关和列表可以在配置中修改；命令不受关键词开关影响。爆典关键词严格匹配 `关键词 @某人 [页码]` 语法。

## 收录规则

- 普通记录保存引用消息的发送者 QQ、昵称快照、文字、图片、QQ 内置表情、商城表情、来源时间和收录信息。
- 被收录消息本身带有回复关系时，会把被回复消息的作者与内容递归保存为本地快照；默认最多 3 层，可配置为 1～10 层。添加命令自身的引用只用于选择来源，不算回复关系。
- 合并转发整体算一条记录，保留节点顺序、节点作者、文字、图片、表情和各节点的回复快照；不支持收录嵌套转发。
- 支持 JPEG、PNG、WebP 和 GIF。文件按内容哈希重命名，JSON 只保存相对路径。
- 头像不会写入 JSON 或磁盘。生成卡片时实时从 QQ 头像接口获取，失败时头像区域留白。
- Bot 自己和其他机器人的触发消息始终忽略；`allow_bot_authors` 默认关闭，开启后也只允许通过人工引用或人工提交的合并转发收录机器人作者。
- QQ 内置表情按表情 ID 原生重放；商城表情会保存本地图片与必要元数据，优先原生重放，失败时降级为本地图片。Unicode Emoji 仍作为普通文字保存。
- 同群内按发送者、消息类型、规范化内容、回复快照和转发节点序列进行 SHA-256 去重；回复不同的相同正文会视为不同记录。
- 语音、视频、文件等不支持的消息段不会保存；完全没有可保存内容时拒绝收录。

## 随机发送

每条普通记录和每个合并转发合集等概率，单次抽取不重复。指定成员时，只检索该成员的普通记录，以及所有节点均明确属于该成员的转发合集。开启“随机发送条数”后，每次会在 `1～send_count` 之间随机选择数量；库存不足时只发送现有记录。

发送方式可选文字或图片卡片。多条普通记录可以聚合成新的合并转发，节点发送者使用对应金句作者的 QQ 和昵称；原生合并转发始终独立回放，避免不受支持的嵌套转发。

图片卡片支持自动高度、尺寸和 CSS 样式，管理页可以一键恢复默认样式。自动高度开启时，插件会让作者信息紧跟内容，并在渲染后安全裁去文转图服务附加的底部画布。卡片使用 AstrBot 的 `html_render()`，渲染内容会交给 AstrBot 当前配置的文转图端点；若不希望群聊内容离开服务器，请部署并配置 AstrBot 自建文转图服务。

含 QQ 表情、商城表情或回复快照的记录会绕过 CSS 卡片并按原生消息链发送，避免信息丢失。

## 爆典合集

`爆典 @某人` 会按记录时间从旧到新列出该成员的全部健康记录。普通记录按原作者显示；只要目标成员出现在某条合并转发的任一节点中，该转发就整体计为一条并原样嵌入合集。多作者转发不会被拆开或重复计数。

默认每页 50 条，可通过 `burst_page_size` 或群级覆盖设置为 1～100。记录超过每页条数时，不会直接发送第 1 页，而是先提示总页数，再使用 `爆典 @某人 页码` 获取。资源缺失记录不计入健康总数，合集标题会单独显示跳过数量。

## 权限和名单

添加、随机查询、爆典、统计、删除分别配置允许角色：Bot 管理员、群主、群管理员、普通群成员或所有人。默认爆典允许群成员，其余默认添加、查询、统计允许所有人，删除仅允许 Bot 管理员。

群与操作者黑名单优先于白名单。禁止收录名单用于保护指定 QQ 用户；无法确认转发节点身份时会失败关闭。

## 存储和备份

默认数据目录：

```text
data/plugin_data/astrbot_plugin_iconic_quotes/iconic_quotes/
├── groups/<群号>.json
├── images/<群号>/<内容哈希>.<扩展名>
├── backups/
└── audit.json
```

JSON 当前使用 Schema v2、临时文件原子替换和 `.bak` 恢复。v1 数据和备份仍可读取，并在下一次修改时备份后惰性升级。达到记录或媒体容量上限时拒绝新增，不会静默淘汰旧记录。数据为明文，请保护 AstrBot 数据目录和导出的 ZIP。

从旧版本升级时，如果新目录为空，插件会自动将 `data/plugin_data/<存储相对目录>` 迁移到 `data/plugin_data/astrbot_plugin_iconic_quotes/<存储相对目录>`，并保留带时间戳的旧目录备份。存储路径配置只能指向插件专属目录内部，不能越界写入其他插件的数据目录。

修改已有数据的存储路径必须通过管理页迁移。迁移完成后旧目录会保留为带时间戳的备份，需由管理员确认后自行清理。

## Plugin Pages

插件详情页中的“群典管理”页面仅通过 AstrBot Dashboard 打开，复用 Dashboard 端口和认证。页面支持：

- 按群分页、搜索和筛选记录
- 查看文字、图片、表情、回复快照、转发节点和记录元数据
- 单条或批量删除及删除审计
- 编辑全局配置和群级覆盖、预览卡片 CSS
- ZIP 导出，以及“上传预检 → 展示新增/重复/冲突/缺图统计 → 管理员确认”的两阶段合并导入
- 显式迁移存储目录

## 冷却与重试

默认全局冷却为 1000ms。冷却或操作进行期间不访问数据，每个群在同一轮冷却中最多收到一次 `群典功能冷却中...`。发送失败默认额外重试两次；超时等结果不确定的失败默认不重试，以免重复发送。

## 已知限制

- 仅支持 OneBot 11 / QQ。
- 仅支持一层合并转发。
- 纯图片记录无法通过字符串删除命令命中，请在管理页删除。
- OneBot 无法返回作者 QQ 时，记录只能进入群级随机池。
- 图片或 JSON 被外部修改后，异常记录不会参与随机发送，需在管理页处理或从备份恢复。
